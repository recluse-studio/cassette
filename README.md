# Cassette

Cassette's original specification is restored from the August 31, 2026 source,
`074f594a0bacc4c08e953acf4539f129eb1f041d`.

The intended product downloads a complete model directly to an external drive,
uses consumer Apple hardware to run it, supports compatible training on that
drive, and makes it available through Codex, Ollama, OpenClaw, Hermes and custom
agents. The original capability, performance, reliability and minimum-code
requirements govern completion.

The August machine implementation was recorded complete through S28, with 307
passing tests at its recorded revision. The complete live product remains
unproved. See [the checked progress and remaining work](FIRST_PRINCIPLES.md).
